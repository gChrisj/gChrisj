## 🦖 Purgebox – Gmail Storage Cleaner

**Overview:**  
A Chrome extension that helps users reclaim Gmail storage by scanning, categorizing, and bulk-deleting emails. Built and shipped end-to-end as a solo developer — live on the Chrome Web Store.

**What I built:**  
- OAuth 2.0 authorization flow and token management  
- Gmail API integration with bulk deletion via `batchModify` (up to 5,000 emails per request)  
- Persistent background service worker with cancel/resume support and real-time progress feedback  
- LemonSqueezy Pro tier payment integration with license key validation and entitlement gating  
- Landing page, Chrome Web Store submission, and Google OAuth verification  

**Links:**  
- [purgebox.app](https://purgebox.app)

**Languages:** JavaScript  
**Tools:** Chrome Extension Manifest V3, Gmail API, OAuth 2.0, LemonSqueezy, Netlify  
**Concepts:** Browser Extension Dev, API Integration, Payment Processing, Full Product Lifecycle
