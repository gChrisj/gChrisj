## 💸 BudgieBuddy – Gamified Budgeting App

**Overview:**  
BudgieBuddy is a mobile-first budgeting app designed to make personal finance fun and engaging. Users complete savings quests, daily challenges, and earn XP while getting guidance from **Budgie**, an AI-powered assistant with memory and personality modes.

**My Role:**  
- Built and designed the app with React Native and Firebase  
- Integrated OpenAI’s GPT API to power the AI assistant  
- Implemented XP, level progression, and long-term memory for AI context  
- Developed savings quest tracking and daily financial challenges

**Links:**  
- [BudgieBuddy Repo](https://github.com/gchrisj/budgiebuddy)

**Languages:** JavaScript  
**Tools:** React Native (Expo), Firebase, OpenAI API  
**Concepts:** Mobile Dev, Gamification, AI Chatbot Integration, UX Design
